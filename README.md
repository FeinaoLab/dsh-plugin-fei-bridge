# 🔌 飞桥插件系统

> 飞桥插件系统 —— 灵活可扩展的插件架构平台

## 📖 项目简介

飞桥插件系统是一套高可扩展性的插件架构框架，支持热插拔、动态加载和第三方集成，帮助开发者快速构建模块化、可插拔的应用系统。

## ✨ 主要特性

- 🧩 **插件架构** —— 清晰的插件生命周期与依赖管理
- 🔥 **热插拔** —— 运行时动态加载/卸载插件，无需重启
- 🔗 **扩展接口** —— 丰富的 Hook 与 API 接口，灵活扩展
- 🌐 **第三方集成** —— 轻松对接外部服务与系统
- 📡 **事件总线** —— 插件间松耦合通信机制
- 🛡️ **沙箱隔离** —— 插件运行环境安全隔离

## 🚀 快速开始

```bash
# 克隆仓库
git clone https://github.com/FeinaoLab/dsh-plugin-fei-bridge.git

# 进入项目目录
cd dsh-plugin-fei-bridge

# 安装依赖
npm install

# 启动开发环境
npm run dev

# 运行测试
npm test
```
